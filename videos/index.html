Slow-paced breathing pacer: 4 seconds in, 6 seconds out

Materials for a brief paced-breathing exercise: a visual pacer at six breaths per minute with no breath holds and no meditation instructions. Everything is generated from code and checked frame by frame.

Qualtrics code

Two ways to run the exercise in a survey. Both hide the Next arrow until the exercise ends, pause if the participant switches tabs, and record compliance data. Setup steps are in the README.

  • Option A: embedded video Plays the MP4 above. Blocks skipping ahead and logs how much was actually watched. JavaScript HTML
  • Option B: live pacer Draws the circle in the page with the same timing. No video to host. JavaScript HTML
